# Second cerveau

Second cerveau personnel, pattern « LLM Wiki » (Karpathy) : `raw/` → `wiki/` →
`docs/graph.json` → page 3D publiée sur GitHub Pages.

Voir `CLAUDE.md` pour le workflow complet.

- `raw/` — notes brutes
- `wiki/` — notes distillées et interconnectées (source du graphe)
- `scripts/generate_graph.py` — régénère `docs/graph.json` depuis `wiki/`
- `docs/` — page GitHub Pages (graphe 3D)
