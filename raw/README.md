# raw/

Zone de dépôt pour les notes brutes : captures de cours, brouillons, liens,
photos de tableau transcrites, idées en vrac. Aucune structure imposée,
aucune exigence de qualité — c'est le brouillon.

Rien ici n'alimente directement le graphe (`docs/graph.json`). Le contenu
de `raw/` doit être distillé à la main (ou avec l'aide de Claude, voir
`CLAUDE.md`) en notes atomiques dans `wiki/` avant de compter.
